3. Из опыта старта dotnet-приложений в контейнере сталкивался с подобными ошибками, если в настройках демона Docker заданы ограничения по ресурсам.
Можно проверить demon.json, секция "default-ulimits":

  "default-ulimits": {
    "nofile": {
       "Name": "nofile",
       "Hard": 300,
       "Soft": 100
    } 
  }

Это минимальные настройки, при которых backend корректно стартует
